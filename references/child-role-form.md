# 孩子角色与技能采集表

这张表用于把孩子的想法变成可以安全接入当前水豚奶茶接物游戏的规格。可以一次填写一个孩子；
如果孩子还没有想好技能，先保留空白，不要替孩子决定。

## A. 账号

```text
账号位（1～4）：
昵称：
密码：
是否在登录页直接显示该密码：是 / 否
```

一个孩子时默认使用账号位 1。账号位与助手位保持一致，不因为新增或删除孩子而重排已经存在的
助手顺序。

## B. 角色素材

```text
图片文件路径：
角色称呼（可与昵称不同）：
保留的特征：
需要清理的背景或文字：
希望的画面大小/站位：
```

素材最好是正面或三分之二立绘，主体完整，背景简单。最终会转换为透明 RGBA PNG；原图保留不覆盖，
游戏副本使用 `assets/helper-1.png`、`assets/helper-2.png` 等稳定文件名。

## C. 角色动作

```text
进场：从哪里进入？是否飞入、走入、旋转、闪现？
施法：举手、挥杖、鼓掌、转身，还是其他动作？
离场：从哪里离开？
节奏：轻快 / 庄重 / 可爱 / 其他
```

单张立绘会用位移、缩放、透明度、摆动和光效模拟动作。进场必须完整结束并控制在 2 秒内；进场时
游戏全局暂停，动作结束后恢复。

## D. 技能规则

```text
技能名称：
什么时候能召唤：沿用当前 200 分召唤，还是明确提出新规则？
实际效果：它改变哪些东西？
作用对象：当前屏幕 / 后续道具 / 水豚 / 分数 / 生命值 / 其他
持续多久：一次性 / X 秒 / 到本局结束
是否允许叠加：
结束后如何恢复：
```

技能规则必须能用一句话判断“什么时候生效、影响什么、什么时候结束”。例如“清除当前屏幕的扣分
道具一次”是明确规则；“让游戏变厉害一点”还不够明确。

## E. 技能特效

```text
主颜色：
玩家看到的效果：光环 / 星星 / 冰冻 / 清场闪光 / 飘字 / 其他
效果出现的时机：进场后 / 施法中 / 技能结束前
是否需要声音：
```

技能特效只负责表达技能，不应偷偷改变分数、血量或碰撞。先实现可读、轻量、移动端流畅的 CSS/DOM
特效；确实需要复杂粒子或新图片时，再制作单独素材。
